# 拾句 · 纸上拼贴诗

中文、固定朝向的三维拼贴工作台。网页纯静态，适合 GitHub Pages；没有账号或服务器保存，工作台、词语篓子、图片缓存使用当前浏览器的 IndexedDB。

## 使用

- 手：拖散页摆放；捏杂志页边往书脊另一边翻页。Shift 抬高纸，Q/E 旋转散页。
- 拖空白桌面平移镜头，滚轮或右下角按钮缩放，百分比按钮复位。
- 刀：沿路径切纸。切线连接边缘或闭合可分离纸片。可以再次裁切碎片；垫板阻止对更低纸层的切割并留下划痕。
- 胶：按住涂抹；20 秒内叠纸接触粘合，干燥后不能新粘。湿度影响黏度、收缩及纸面变形。
- 词语篓子：收藏纸片，刷新后仍可取出。
- 导出：选中作品放入导出框，调整角度与背景，保存带素材出处的 PNG。

## 物理实现及范围

`src/physics.js` 是专用 CPU XPBD 薄片求解器（拉伸、弯折、捏点约束、局部胶层收缩、纸面接触），配表面 SPH 胶液近似。纤维参数、胶量、涂布形状和粘贴时刻影响形变。胶液粒子转换成连续密度胶膜渲染，不直接显示粒子球。

这是浏览器实时近似，不是材料实验级纸纤维/三维流体仿真。纸张接触以层高和局部约束处理，没有完整自碰撞与撕裂断裂力学。胶膜在纸面流动，没有离开纸面的自由液滴。翻页采用书脊约束与手动角度驱动。复杂形状、多层大量湿胶时性能取决于设备。

切割使用 polygon-clipping；新碎片继承切割瞬间形状，不凭空施加冲量。连续细网格与平滑法线用于纸面渲染。Three.js 提供 WebGL 场景，earcut 处理三角剖分。

## 内容

文章由 GitHub Actions 每小时（UTC 第17分钟）提前采集，每来源每批最多8篇，累计保存在 materials.json；collection-state.json 保存已检查链接，防止每次重复抓取同一批。定时任务可能排队延迟，不承诺准点。公开仓库长期无活动时，GitHub 可能暂停定时任务。

当前采集白名单：Water Space、和光同尘、Tuorui Peng、汐月观测站、可乐君de小站。只接收有 CC BY-NC-SA 4.0 许可依据的中文正文，不收录标明禁止改编的内容、转载或翻译；各来源可能暂时连接失败，失败不会清空已采集素材。每篇保留作者、原文链接、许可与采集时间，不复制来源网站图片。新杂志使用随游戏发布的 CC0 配图，仍保留图片署名。

访客只读取 Pages 同站 materials.json，不请求原文章网站；每次取书重新检查预存库，断网时可读取上一次已缓存的库。优先混合不同作者和题材，通常一本10篇，不足10篇则发剩余篇数。全部取过时显示“现有素材你都取过啦，等会再来”，不以旧文或原创备用文本补齐。没有新文章时等待不保证有补充。

已取历史沿用 IndexedDB 的 issued-articles-v1，按文章标识、标题、正文哈希原子去重，刷新、撤销、工作台恢复和并发标签页不重置。无账号，去重覆盖当前站点及浏览器；换设备或清除网站数据会失去历史。旧书、词语篓子与作品不删除。新文章与拼贴遵守署名、非商业、相同方式共享；旧 BY-SA 文章与新 BY-NC-SA 不兼容的混合作品会提示分开导出。

仓库根目录发布 dist 的网站文件、collect-materials.mjs 和 .github/workflows/materials.yml；Pages 使用 GitHub Actions。工作流安装固定版本 cheerio 后采集，提交素材库与进度，构建只含静态网站文件的 Pages artifact 并部署。首次已提前采集，不必等下一小时。

## 开发

Node.js 24。`npm install`，`npm test`，`npm run build`，`npm run dev`。预览 `http://127.0.0.1:8777/`。

发布 `dist/` 根目录下的 index.html、app.js、style.css、seed.json、art-0.jpg 至 art-9.jpg、THIRD_PARTY_NOTICES.txt。Pages 设置为 main 分支根目录。

测试覆盖重复裁切、闭合切口、20 秒固化边界、纸张捏点响应、不同纤维与粘贴时刻的形变差异、液体流动及干后停止。

## 保存

本地数据不会自动跨设备同步。清除网站数据会删除缓存；使用「备份工作台」保存 JSON，随后可用「恢复备份」取回。素材出处和布局随备份保存，图片可再次加载。

纸张交互：未粘合的书页、散页与裁片保持平面刚性；胶液仍可流动，只有识别粘合后才启用纸张形变。干燥收缩目标与上限降为原来的 50%。

2026-10-16：纸片碰撞改用完整轮廓（含旋转、背面和孔洞），拖动整组抬高、落下和旋转均计算支撑高度；纸层加厚间距并纳入胶膜及起皱高度。原创白话回退库以 CC0 提供，见 source.zip 中 src/modern-texts.js。已有杂志和裁片保留原文，新取杂志使用新版内容来源。

2026-10-17：裁刀保留鼠标射线，在各层真实纸面求交，刀路预览不再额外抬高；桌面、垫板与书页共用落点高度，支撑移开后自动落桌；平放刚性散纸不投悬浮阴影，抬起、叠放和起皱时保留淡阴影。
